# P1 착수 전 결정 (2026-11-06)

설계서: `CBAO_P1_통합설계서_v1.1.md` (GPT 작성, 사용자 승인). 기준: 웹 `19757b6`, 심부름꾼 0.8.1.

- 설계서는 채택. 코드 결함 5건(대화방·작업 카드 비원자 생성, 검토 없이 반영 가능, 반영 직전 재검증 없음, 승인 종류 무관 done, 보호 파일 제외 dirty) 모두 사실로 확인.
- **(가) "검토 없이 수용" 결재 경로를 둔다.** 소유자가 사유를 적고 명시적으로 결재하며 기록에 "검토 생략"이 남는다. SHA 불일치는 예외 없이 차단. 검토가 있었는데 pass 가 아니면 클릭 한 번으로 넘기지 않는다.
- **(나) P0(실 PC 한 건 완주) 결과가 나올 때까지 P1 구현을 시작하지 않는다.** P0 합격표는 `docs/DATA_MODEL.md` 7절.
- 납품은 두 번: 1차 읽기 모델·화면·결재 효과 분리(P1-02~04), 2차 SHA 게이트·여권(P1-05~06). 각각 보고서·시험 포함. 별도 작업 가지, main 반영은 승인 후.
- 대화방이 있는 작업의 화면 캡처는 Firebase 로그인이 필요해 자동 캡처 불가 → 사용자 PC 확인 항목으로 분류.
