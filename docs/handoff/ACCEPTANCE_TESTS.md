# 실제 앱 통합 후 인수 시험

아래 항목은 **개발자가 실제 앱에서 수행할 시험 계획**이다. 이 패키지에서 통과한 결과로 취급하지 않는다. 기초 코드·계약 검증 결과는 `VALIDATION_REPORT.md`에 따로 기록한다.

| ID | 시험 | 통과 조건 |
|---|---|---|
| AT-01 | 기본 앱 진입 | 메인 대시보드가 열리고 기존 기능과 경로 유지 |
| AT-02 | 보기 전환 | 픽셀 사무실 ↔ 대시보드 전환, 뒤로가기·직접 링크 정상 |
| AT-03 | 실제 member 바인딩 | 자리 이름 대신 member_id로 연결. 미연결은 명시 표시 |
| AT-04 | 프로젝트 필터 | 위치 보존, 다른 프로젝트 작업을 idle로 조작하지 않음 |
| AT-05 | 가구·캐릭터 독립성 | 캐릭터 하나의 상태·선택이 나머지 장면을 재생성하지 않음 |
| AT-06 | 픽셀 아트 품질 | 따뜻한 스타일, 일정한 픽셀, 독립 에셋. 한 장 배경이 최종본 아님 |
| AT-07 | 가림·접지 | 책상 앞뒤·캐릭터·의자의 가림, 바닥 위치 자연스러움 |
| AT-08 | 자리 클릭 | 해당 팀원·동일 task를 기존 상세 화면으로 연결 |
| AT-09 | 새 지시 | 프로젝트·담당만 채움. 확인 없이 실행하지 않음 |
| AT-10 | 관리형 live 실행 | 확인된 run에서만 작업 동작. dashboard와 상태 일치 |
| AT-11 | 외부 수동 보고 | 보고 시각·출처 표시, 자동 heartbeat·typing 없음 |
| AT-12 | 실행 성공·업무 완료 | run 성공은 실행 종료. artifact 제출·사용자 승인 전 done을 추정하지 않음 |
| AT-13 | 승인석 | 권한 있는 승인 요청 수와 기존 승인함을 연결 |
| AT-14 | 중지 | 전달 대기·처리 중·종료 확인 구분, 요청만으로 취소 완료 금지 |
| AT-15 | 지연·연결 끊김 | 45/90초 경계, 마지막 확인 시각, 업무 상태 임의 변경 없음 |
| AT-16 | 재접속 | 누락 상태 복구, 중복·역순 이벤트가 상태를 되돌리지 않음 |
| AT-17 | PC와 프로세스 구분 | PC만 살아 있을 때 타이핑을 계속하지 않음 |
| AT-18 | 키보드·스크린리더 | 모든 행동 DOM 대안, 초점 복귀, 중복 낭독 방지 |
| AT-19 | 모바일 | 390×844 기준 목록·패널 사용 가능, 화면 스크롤 방해 없음 |
| AT-20 | 화면 크기·배율 | 1366×768 및 1920×1080, DPR 1/2에서 라벨·hit 영역 정렬 |
| AT-21 | 움직임·소리 | reduce motion, 음소거 기본, 숨김 탭 동작 정지 |
| AT-22 | 리소스 정리 | 20회 진입·이탈 후 canvas/ticker/observer/구독 중복 없음 |
| AT-23 | renderer/에셋 실패 | DOM 업무 목록 유지, 오류·재시도 표시 |
| AT-24 | 보안·live/demo | 권한 밖 자료 차단, XSS 문자열 텍스트 표시, demo 혼입 차단 |
| AT-25 | 기존 업무 회귀 | 원래 지시·검사·인계·승인·중지 흐름 유지 |
| AT-26 | 실제 환경 | 사용자 승인 샘플로 실제 관리형 1건·외부 수동 1건 검수 |

모든 결과에는 날짜, 환경, 실행한 절차, 실제 결과, 증거 캡처/로그를 기록한다. 테스트하지 않은 브라우저·PC의 성능을 추정해서 통과로 표기하지 않는다.
