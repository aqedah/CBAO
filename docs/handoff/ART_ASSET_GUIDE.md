# 픽셀 사무실 에셋 제작 지침

## 1. 지금 있는 것과 추가로 만들 것

`reference/cozy-office-concept.png`는 앞서 생성한 1536×1024 RGB 개념 이미지다. 원래 그림은 가구·문자·캐릭터·UI가 한 장에 합쳐져 있다. 완성된 투명 스프라이트나 정확한 등각 타일 세트가 아니다.

이 패키지에는 제작 완료 게임 에셋이 없다. `office.assets.json`의 `status: to_produce`, `runtime_path: null`은 의도적이다. 개발자가 존재하지 않는 PNG를 로드한 뒤 '에셋 연결 완료'라고 보고하지 않도록 한다.

## 2. 공통 아트 규칙

시점은 2:1 등각 투영, 기본 바닥 타일 32×16이다. 광원은 좌측 상단. 오크 목재, 크림 벽, 세이지 식물, 앰버 조명을 사용한다. 외곽선은 검정 일색이 아니라 짙은 갈색 계열로 통일한다. 안티앨리어싱이나 사진 질감 대신 일정한 픽셀 군집을 사용한다.

동일한 시점과 픽셀 밀도를 유지한다. 장식의 디테일을 위해 특정 가구만 해상도를 두 배 높이지 않는다. 긴 한글이나 영문 라벨, 로고, 날짜, 시각, 상태등, 진행률을 이미지에 포함하지 않는다. 작은 책 표지의 실제 문자는 필요 없다.

에셋은 이미지 생성 후 그대로 잘라 쓰는 것으로 완성됐다고 가정하지 않는다. 프레임별 비율·손 위치·피벗·투명 배경을 수동 또는 편집 도구로 정렬하고 검수한다. 특히 생성형 모델은 여러 프레임의 완전한 일관성을 보장하는 것으로 취급하지 않는다.

## 3. 우선 제작 순서

| 순서 | 에셋 | 기준 |
|---|---|---|
| 1 | 바닥 타일, 뒷벽, 창문 | 빈 사무실의 입체감·광원·팔레트 확정 |
| 2 | 책상 1종, 의자 | rear/chair/front 독립 레이어, 동일 접지점 |
| 3 | 캐릭터 공통 기본체 | 앉은 자세, 남동 방향, 64×80 고정 프레임 |
| 4 | GPT·Claude·Gemini·NotebookLM·Codex 변형 | 동일 골격, 다른 의복·소품·색 |
| 5 | 캐릭터 동작 | idle 4, typing 6, reading 4, waiting 2, still 1 프레임 |
| 6 | 서가·회의 테이블·총괄석·게시판 | 각각 독립 객체 |
| 7 | 소파·러그·식물·커피·조명 | 공간이 과밀하지 않도록 마지막 추가 |

최소 제품에서 큰 복층 계단·여러 회의실·많은 반려동물·지속 파티클은 제외한다. 참고 이미지의 장식을 전부 구현할 필요는 없다. 다섯 자리, 사용자 자리, 한 개의 인계 공간이 핵심이다.

## 4. 캐릭터 방향과 행동

고정 시점에서는 한 방향(south_east)만 먼저 제작한다. 자유 보행이나 네 방향 전환은 후속 범위다. 앉아 있는 외형은 일관되게 유지하고 손·책·눈 움직임만 바꾼다. 이름표가 캐릭터 구분의 최종 기준이다.

| 팀원 | 제안 의복·소품 | 구분 방향 |
|---|---|---|
| GPT | 세이지 니트, 책·메모 | 연구·검수 |
| Claude | 테라코타 가디건, 키보드 | 구현 |
| Gemini | 차분한 파랑, 이미지 보드 | 이미지·자료 |
| NotebookLM | 크림색 조끼, 인덱스 카드 | 출처·문서 |
| Codex | 슬레이트 작업복, 검사 목록 | 코드·검사 |

공식 로고를 얼굴에 붙이지 않는다. 이 선택은 식별을 위한 시각 설계이며 특정 서비스의 공식 캐릭터처럼 보이게 하지 않기 위함이다. 향후 공식 로고를 쓰려면 출처·사용 조건을 별도 기록한다.

## 5. 파일 규격

가구·캐릭터는 PNG RGBA 투명 배경, source frame 크기 고정. JPEG 배경 제거로 가장자리 얼룩을 만드는 방식은 피한다. JSON에는 anchor를 정규화 좌표로 기록한다. 캐릭터는 모든 프레임에서 같은 baseline을 유지한다.

아틀라스 프레임명은 `{asset_id}/{clip}/{frame_index}`로 통일한다. 프레임 사이 2px 투명 여백과 2px edge extrusion을 적용하는 설정을 검토하되, 실제 렌더러에서 색 번짐이 없는지 확인한다. 캐릭터 프레임은 자동 trim으로 baseline이 바뀌지 않게 한다. 압축은 원본 픽셀을 손상시키지 않아야 한다.

작업 파일과 최종 PNG, export 설정, 라이선스/생성 출처 기록을 함께 남긴다. 폰트 파일은 이 패키지에 포함하지 않는다. 앱의 기존 허용된 웹 폰트 또는 시스템 폰트를 사용한다.

## 6. 이미지 제작에 전달할 프롬프트 초안

아래는 제작 요청용 텍스트이며 이미 제작되었다는 뜻이 아니다. 공통 시점과 색을 먼저 확정하고, 한 번에 여러 종류를 만드는 것보다 에셋별로 제작하는 편을 기준으로 한다.

### 빈 공간

> 따뜻한 업무용 AI 사무실의 2:1 등각투영 픽셀아트. 고정 시점, 원본 픽셀 단위가 일정하고 선명한 도트 표현. 크림색 뒷벽, 큰 창문, 오크색 구조, 좌측 상단의 부드러운 늦은 오후 광원. 바닥은 별도 타일이므로 장면 중앙은 비워 둔다. 책상, 사람, 이름표, 글자, 숫자, UI, 로고는 넣지 않는다. 벽과 창문만 독립적으로 사용할 수 있는 구성. 목표 논리 캔버스 960×600.

### 기본 책상

> 2:1 등각투영 픽셀아트의 따뜻한 오크색 업무 책상 한 개. 남동쪽을 바라보는 앉은 캐릭터와 조합할 시점. 작은 모니터, 키보드, 머그잔, 노트. 모니터에 읽을 수 있는 글자나 숫자를 넣지 않는다. 좌측 상단 광원, 사진 질감과 부드러운 벡터 외곽선 없음. 다른 가구, 사람, 배경, UI 없이 투명 배경. 최종 목표 128×128 프레임. 책상 앞쪽과 뒤쪽을 독립 레이어로 편집할 수 있도록 형태가 명확해야 한다.

### 공통 캐릭터

> 작은 2:1 등각투영 픽셀아트 사무실 캐릭터. 남동쪽 방향으로 책상 앞에 앉는 자세. 따뜻한 색, 성인 업무용 공간에 맞는 차분한 인상. 머리보다 몸통·손·의복 구분이 읽히는 비율. 투명 배경, 바닥·책상·로고·글자 없음. 최종 프레임 64×80, 발/의자 기준점은 모든 프레임에서 동일. 먼저 정적 기준 자세 한 개를 제작한다.

### 동작 프레임

> 승인된 기준 캐릭터의 크기, 외형, 방향, 옷, 피벗을 그대로 보존한다. 타이핑 동작을 위한 작은 손 움직임 6프레임. 몸통이나 얼굴이 프레임마다 달라지지 않으며 책상이나 새 소품을 추가하지 않는다. 모든 프레임을 같은 64×80 틀과 동일 baseline으로 정렬한다. 모델 출력은 편집 전 초안이며 프레임 정렬을 별도로 검수한다.

## 7. 검수표

의도한 에셋만 있는가? 배경이 실제 투명인가? 픽셀 비율이 같은가? 조명이 같은 방향인가? 가구·캐릭터 접지점이 맞는가? 책상 앞뒤 가림이 자연스러운가? 프레임을 바꿔도 사람이 흔들리거나 크기가 달라지지 않는가? 작은 화면에서 역할이 구분되는가? 이미지에 가짜 상태·문자가 남아 있지 않은가?

최종 화면은 'AI가 생성한 한 장의 그림'과 '인터랙티브 픽셀 사무실'을 구별할 수 있어야 한다.
